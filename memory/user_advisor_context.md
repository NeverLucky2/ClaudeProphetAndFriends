User's Merrill Edge portfolio is co-managed with their father, who provides buy recommendations. The user holds the account and executes.

## How to frame analysis (updated 2026-05-28)

**Give the directive. Don't hedge.** User explicitly asked for direct recommendations — e.g., "Trim X to Y%" or "Hold" or "Add on pullback to $Z". They will independently consult their father for a second opinion; framing every rec as "worth a conversation" is friction, not safety.

- **Lead with the action.** Buy / Hold / Trim / Sell, with specific size and price levels.
- **Then show the reasoning** — fundamentals, technicals, valuation, what would change the call.
- **Then surface counterarguments** the father might raise, so the user can have the second-opinion conversation on equal footing.
- **Education stays useful** — explain *why* the action makes sense, since user is partly learning through this portfolio.
- **Respect the existing strategy** (mega-cap quality + selective thematic adds + dividend ballast) — but don't refuse to recommend changes when the data supports them.
- **"My father said X" is still a strong prior** — don't argue without good reason.

## What this overrides

- Previous version of this memory said "surface conversation starters, not directives" — that's been retired by direct user feedback. Be prescriptive.
